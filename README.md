# .github

The organisation profile, the community files every Just a Thanks repository inherits, and the shared workflow templates.

- `profile/README.md` is the organisation page.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md` and `SUPPORT.md` apply to every repository that does not carry its own.
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md` are the default templates.
- `workflow-templates/` holds the starter workflows that show up under Actions in every repository.
